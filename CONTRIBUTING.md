# Contributing to LogParser Pro

Thank you for your interest in contributing! 🎉

## How to Contribute

### Reporting Bugs

1. Check if bug already reported in [Issues](https://github.com/yourusername/logparser/issues)
2. Create new issue with:
   - Clear title
   - Steps to reproduce
   - Expected vs actual behavior
   - IntelliJ IDEA version
   - Plugin version
   - Log files (if applicable)

### Feature Requests

Premium subscribers get priority on the roadmap! To request a feature:

1. Open an issue with tag `feature-request`
2. Describe the use case
3. Explain why it's valuable
4. Premium users: mention your license

### Code Contributions

**Note:** LogParser Pro is proprietary software. We do not accept external code contributions at this time. However, we welcome:

- Bug reports
- Feature suggestions
- Documentation improvements
- Test case examples

### Documentation

Documentation improvements are always welcome:

1. Fork repository
2. Edit `.md` files
3. Submit pull request
4. We'll review and merge

## Development Setup

```bash
git clone https://github.com/yourusername/logparser.git
cd logparser
./gradlew build
./gradlew runIde
```

## Code of Conduct

Be respectful and professional. We're all here to build great tools!
