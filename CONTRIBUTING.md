# Contributing to LogParser Pro

Thank you for your interest in contributing! 🎉

## How to Contribute

### Reporting Bugs

1. Check if bug already reported in [Issues](https://github.com/yourusername/logparser/issues)
2. Create new issue with:
   - Clear title
   - Steps to reproduce
   - Expected vs actual behavior
   - IntelliJ IDEA version
   - Plugin version
   - Log files (if applicable)

### Feature Requests

To request a feature:

1. Open an issue with tag `feature-request`
2. Describe the use case
3. Explain why it's valuable

### Code Contributions

LogParser Pro is open source under the Apache License 2.0 — code contributions are welcome:

1. Fork the repository
2. Create a feature branch
3. Add tests for your change (`./gradlew test`)
4. Open a pull request

By contributing you agree that your contribution is licensed under Apache-2.0.

### Documentation

Documentation improvements are always welcome:

1. Fork repository
2. Edit `.md` files
3. Submit pull request
4. We'll review and merge

## Development Setup

```bash
git clone https://github.com/JirakJ/logparser-premium-plugin.git
cd logparser-premium-plugin
./gradlew build
./gradlew runIde
```

## Code of Conduct

Be respectful and professional. We're all here to build great tools!
